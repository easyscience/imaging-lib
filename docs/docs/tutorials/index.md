# :material-school: Tutorials

This section presents a collection of **Jupyter Notebook** tutorials that
demonstrate how to use EasyImaging for various tasks. These tutorials
serve as self-contained, step-by-step **guides** to help users grasp the
workflow of data analysis using EasyImaging.

Instructions on how to run the tutorials are provided in the
[:material-cog-box: Installation & Setup](../installation-and-setup/index.md#how-to-run-tutorials)
section of the documentation.

The tutorials are organized into the following categories:

## Core components

- [The **Measurement** class](measurement.ipynb) – Learn how to load in a measurement, inspect its data and create regions of interests.
- [The **SampleModel** class](sample_model.ipynb) - Learn how to create a crystallographic model of your sample and calculate its wavelength spectrum.
