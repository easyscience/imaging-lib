# :material-information-slab-circle: Introduction

## Description

**EasyImaging** is a software for performing Bragg-edge calculations
based on a crystalliographic model and refining its parameters against
experimental data.

**EasyImaging** is developed both as a Python library and as a
cross-platform desktop application.

Here, we focus on the Python library. For the graphical user interface
(GUI), please see the corresponding
[GUI resources](https://easyscience.github.io/imaging-app).
